# MCP

The Model Context Protocol (MCP) is an open standard for connecting LLM applications to external tools and data sources. An [[MCP]] server exposes capabilities — such as querying a [[Knowledge Graph]] — to clients like [[AI Agent|AI Agents]] or IDEs.

MCP lets [[Graphify]] expose graph operations (query, shortest path, communities) as tools, and it lets [[LLMs]] call [[Automation]] endpoints. It is a key enabler of composable [[Software Architecture]] for agent systems.
