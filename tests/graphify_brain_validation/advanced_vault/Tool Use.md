# Tool Use

Tool Use is the ability of an [[LLMs|LLM]]-based [[AI Agent]] to invoke external functions — databases, APIs, or an [[MCP]] server. Tool use turns a chatbot into an agent that can act on the world, including querying a [[Knowledge Graph]] via [[Graphify]].

Tool use is wired together by the [[Orchestrator]] and validated by the [[Reviewer]]. It is a defining capability of modern agentic [[Software Architecture]].
