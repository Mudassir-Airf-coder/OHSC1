# AI Agent

An AI Agent is an autonomous system that perceives an environment, plans, and acts to achieve goals. Agents are built on [[Artificial Intelligence]] and [[Machine Learning]], often using [[Neural Networks]] for perception and a [[Knowledge Graph]] for structured memory and reasoning.

Agents frequently operate over personal knowledge stored in [[Obsidian]] and can use [[Graphify]] to turn that knowledge into a navigable graph. Coordinating many agents and their graphs is part of [[Graph Engineering]] and is orchestrated by an [[Orchestrator]].
