# Obsidian

Obsidian is a local-first note-taking application that stores notes as plain Markdown files. Its bidirectional [[Wikilinks]] let users build a personal [[Knowledge Graph]] by hand, while plugins and external tools such as [[Graphify]] can extract a richer semantic graph automatically.

Obsidian is a common surface for [[AI Agent|AI Agents]] that read and organize personal knowledge, and it benefits from [[Graph Engineering]] practices when vaults grow large. Vault automation can be driven by [[Vault Automation]] scripts and governed by [[Knowledge Management]] discipline.
