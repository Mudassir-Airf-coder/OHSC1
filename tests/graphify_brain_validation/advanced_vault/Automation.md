# Automation

Automation is the use of software to perform tasks without continuous human intervention. In agent systems, [[Orchestrator|Orchestrators]] and [[Vault Automation]] scripts automate knowledge work, from extraction via [[Graphify]] to report generation.

Automation is a goal of many [[AI Agent|AI Agents]] and is governed by [[Software Architecture]] and the [[Reviewer]] quality gate. It overlaps with [[MCP]] tool exposure for programmable control.
