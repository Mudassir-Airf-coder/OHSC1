# LLMs

Large Language Models (LLMs) are transformer-based neural networks trained on vast text corpora to predict the next token. They power chat assistants, code generation, and the reasoning layer of many [[AI Agent|AI Agents]].

LLMs are built with [[Deep Learning]] and [[Neural Networks]], and are evaluated with [[Evaluation]] frameworks. They are exposed through an [[MCP]] server interface so agents can call them as tools. Their outputs are often grounded in a [[Knowledge Graph]] for factual consistency.
