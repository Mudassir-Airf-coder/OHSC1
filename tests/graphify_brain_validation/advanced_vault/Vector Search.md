# Vector Search

Vector Search retrieves items by semantic similarity over learned embeddings rather than exact keyword match. It is a core capability of [[Deep Learning]] and [[Neural Networks]], and it complements a [[Knowledge Graph]] by enabling fuzzy recall of related concepts.

Vector search powers retrieval-augmented generation for [[AI Agent|AI Agents]] and is often combined with the structured recall provided by [[Graphify]] and [[Obsidian]]. It is an important technique within [[Graph Engineering]] for large corpora.
