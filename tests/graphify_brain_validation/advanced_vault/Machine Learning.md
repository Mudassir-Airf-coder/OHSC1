# Machine Learning

Machine Learning (ML) is a subfield of [[Artificial Intelligence]] that builds models which improve their performance on a task through experience (data) rather than explicit programming. Core families include supervised learning, unsupervised learning, and reinforcement learning.

ML provides the statistical foundation for [[Neural Networks]] and for the perception modules used by [[AI Agent|AI Agents]]. The features and labels an ML model learns are often grounded in entities drawn from a [[Knowledge Graph]]. Practitioners track experiments and results inside tools such as [[Obsidian]] and govern them with [[Evaluation]].
