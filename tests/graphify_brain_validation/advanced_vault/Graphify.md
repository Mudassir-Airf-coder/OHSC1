# Graphify

Graphify is a knowledge-graph extraction engine. Given a folder of mixed content (markdown, code, PDFs, images), it produces a queryable [[Knowledge Graph]] with entities, relationships, and communities. Graphify infers both explicit (wikilink-based) and implicit semantic relationships.

Graphify is useful for analyzing an [[Obsidian]] vault and for giving [[AI Agent|AI Agents]] a structured memory layer. It is a practical application of [[Graph Engineering]] within the broader [[Artificial Intelligence]] toolbox and is exposed through an [[MCP]] server.
