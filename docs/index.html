Local · Multi-agent · Vault-safe

Control your Obsidian vault from any AI tool.

OHSC is a local multi-agent control plane for Obsidian. One skill file. One CLI. Safe notes, links, search, snapshots — and Graphify knowledge graphs.

Get started View on GitHub → Agent Skill
one-liner install
$git clone https://github.com/Mudassir-Airf-coder/OHSC1.git && cd OHSC1 && pip install -e . && ohsc run
# then set OHSC_VAULT_ROOT to your Obsidian vault path

How agents use OHSC

1
Install & configure
Clone, pip install -e ., set OHSC_VAULT_ROOT.
2
Start a session
Run ohsc run — copy the token if needed.
3
Load the skill
Point the AI tool at skills/OHSC_AGENT_SKILL.md.
4
Discover & execute
ohsc capabilities --json → natural language or Graphify.

Commands you’ll use daily

ohsc run

Start session and print token.

ohsc activate

Gateway health & capability status.

ohsc agents

List all registered agents.

ohsc "…"

Natural-language vault task.

ohsc --graphify build

Build semantic knowledge graph.

ohsc doctor

Diagnostics when something feels off.
